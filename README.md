# Personal Portfolio Website

## 📌 Project Overview

This project is a modern and fully responsive personal portfolio website developed using React.js. It showcases personal projects, technical skills, social links, and contact functionality with a clean and interactive user interface.

The portfolio was built to create a professional online presence and demonstrate frontend development skills through modern UI/UX practices.

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/SanaShaikh171/FUTURE_FS_01.git
```

### Navigate to Project Folder

```bash
cd my-portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```
