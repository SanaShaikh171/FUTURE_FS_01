# Personal Portfolio Website

A responsive personal portfolio website built with React.js as part of my Full Stack Web Development Internship at Future Interns.

## Live Demo

https://future-fs-01-ten-gamma.vercel.app/

## Features

* Responsive design
* About and skills sections
* Project showcase
* Contact form using EmailJS
* Social media links
* Interactive UI and animations
* Mobile-friendly layout

## Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* React Icons
* EmailJS
* Vercel

## Running Locally

```bash
git clone https://github.com/SanaShaikh171/FUTURE_FS_01.git
cd FUTURE_FS_01
npm install
npm run dev
```

## What I Learned

* React component structure
* Responsive web design

* Integrating EmailJS
* Deploying a frontend application with Vercel
