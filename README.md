Portfolio Website

A modern and responsive full-stack portfolio website built using React and Node.js.
This project showcases my skills, projects, and contact information in a professional portfolio format.

🚀 Live Demo:
Frontend Deployment:
https://future-fs-01-ten-gamma.vercel.app/

Backend Deployment:
https://portfolio-backend-3g6z.onrender.com

📌 Features:
Modern glassmorphism UI
Responsive design for mobile and desktop
React-based frontend
Backend integration using Express.js
Contact form functionality
GitHub, LinkedIn, and email integration
Smooth animations and hover effects
Deployed using Vercel and Render

🛠️ Tech Stack:
Frontend
React.js
CSS3
Vite
React Icons
Backend
Node.js
Express.js
CORS
Deployment
Vercel (Frontend)
Render (Backend)

⚙️ Installation & Setup:
Clone Repository:
git clone https://github.com/SanaShaikh/FUTURE_FS_01.git
Install Frontend Dependencies:
npm install
Run Frontend
npm run dev

°Frontend runs on:

http://localhost:5173
🔧 Backend Setup

Open another terminal:
cd backend

Install backend dependencies:
npm install

Run backend server:
node server.js

Backend runs on:
http://localhost:5000
